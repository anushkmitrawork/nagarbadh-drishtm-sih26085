# 🔭 Future Work

NagarBadh Drishtm is an evolving project.

Possible future directions include:

## Rainfall and nowcasting integration

- Automated rainfall-data ingestion
- Doppler-radar nowcast integration
- Automated rainfall-to-model forcing

## Hydraulic automation

- Automated model execution
- Continuous event updates
- Automated hydraulic-output ingestion

## Flood intelligence

- Higher-resolution inundation modelling
- Expanded road-impact analytics
- Operational alerting
- Flood-safe navigation integration

## 3D / digital twin

- Further integration of geographically accurate 3D environments
- Interactive flood visualisation
- Digital-twin-oriented urban resilience workflows

## Research

- Validation and further sensitivity analysis
- Formal publication of the associated research
- Expansion of the literature base

Future work is deliberately separated from implemented functionality so that the repository remains technically honest.
