# 🌱 Project Origin

## Second-Semester MCA Project

NagarBadh Drishtm originated as a second-semester MCA project.

The initial focus was hydro-spatial analysis of an urban environment using terrain and hydrological information to understand waterlogging behaviour.

The project started from a GIS-oriented representation:

- DEM and terrain
- Hydrological derivatives
- Flow behaviour
- Waterlogging susceptibility
- Spatial risk representation
