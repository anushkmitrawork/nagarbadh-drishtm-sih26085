# 🌱 Project Origin

## Second-Semester MCA Project

NagarBadh Drishtm originated as a second-semester MCA project.

The initial focus was hydro-spatial analysis of an urban environment using terrain and hydrological information to understand waterlogging behaviour.

The project started from a GIS-oriented representation:

- DEM and terrain
- Hydrological derivatives
- Flow behaviour
- Waterlogging susceptibility
- Spatial risk representation

This initial stage established the conceptual and computational foundation from which the later drainage, hydraulic and decision-support work evolved.

---

## The first research question

> **Where does water go?**

This question led to terrain and hydrological modelling.

The next stages were driven by increasingly practical questions rather than by a single fixed architecture.

That evolution is documented in [Project Story](project-story.md).
